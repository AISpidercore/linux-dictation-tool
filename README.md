## Overview

A fully offline voice-to-text dictation tool for Linux using whisper.cpp. No cloud dependencies, no internet required.

## Features

- 🎤 High accuracy speech recognition (powered by whisper.cpp)
- 🌍 Support for multiple languages
- ⚙️ Easily customizable commands and settings
- 💻 Lightweight and efficient performance
- 🔒 Completely offline - privacy-focused
- 🚀 Fast and responsive

## Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AISpidercore/linux-dictation-tool
   cd linux-dictation-tool
   ```

2. **Run the installation script:**
   ```bash
   bash setup.sh
   ```

3. **Launch the dictation tool:**
   ```bash
   dictation-tool
   ```
