# Linux Dictation Tool

## Features
- High accuracy speech recognition
- Support for multiple languages
- Easily customizable commands
- Lightweight and efficient

## Quick Start
1. Clone the repository: `git clone https://github.com/AISpidercore/linux-dictation-tool`
2. Navigate to the repository folder: `cd linux-dictation-tool`
3. Run the installation script: `bash install.sh`
4. Launch the dictation tool: `dictation_tool`
